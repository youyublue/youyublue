# 给云朵送一程

一部约 57 秒的日式手绘动画风格短片：住在山间的小女孩，帮一朵迷路的小云回到天空。

画面全部由代码逐帧绘制，配乐和音效由程序合成，两句台词用离线中文语音模型生成。

## 文件

- [`index.html`](index.html)：单文件播放页，视频以 base64 嵌在页面里，下载后用浏览器打开就能离线看（快捷键：`Space`/`K` 播放暂停 · `←`/`→` 跳 5 秒 · `M` 静音 · `F` 全屏）。
- [`cloud-home.mp4`](cloud-home.mp4)：普通视频文件，1920×1040，24 fps，H.264 + AAC。

## 分镜对照

| 时间 | 画面 | 声音 |
|---|---|---|
| 0–6 s | 金色傍晚的山谷小镇，小火车冒着烟穿过山谷，电线杆延向远方；片名浮现 | 蝉鸣、风、远处的汽笛，钢琴琶音 |
| 6–13 s | 门打开，红围巾女孩从屋里走出来；台阶上灰扑扑的小云抖了抖，落下一滴雨 | 开门声、脚步、"啾"、雨滴声 |
| 13–21 s | 女孩蹲下伸手，小云飘进她掌心；她抬头望向山顶（主观镜头），笑着说话 | 女孩："我送你回家。" |
| 21–30 s | 侧面跟拍：她捧着小云跑过田野、爬上花坡，围巾在身后飞，草叶掠过镜头 | 脚步、草叶沙沙声，音乐变亮 |
| 30–40 s | 山顶背影：张开双臂，小云被风托起又落下；她解下围巾迎风扬起 | 风渐强，钢琴和弦乐 |
| 40–49 s | 小云乘风飞进晚霞里的大云，大云亮起来；细雨落下，花上闪着光 | 竖琴般的上行音、铃声、雨声 |
| 49–55 s | 雨停，女孩头顶出现一道小彩虹，她伸手接住飘来的花瓣，镜头拉远 | 旁白："有时候，温柔就是陪你走一段路。" |
| 54–57.5 s | 片尾文字：愿每一朵迷路的云，都能找到回家的风。 | 尾和弦 |

## 源码

| 文件 | 作用 |
|---|---|
| `src/lib.js` | 工具函数、积云的"团块"画法、小云角色、花和闪光、飘带、字幕、水彩纸纹理与柔光后期 |
| `src/girl.js` | 女孩：正面/背面一套（门口、特写、山顶），侧面奔跑一套；表情、眨眼、口型、围巾 |
| `src/shots.js` | 各场景（山谷、家门口、仰望、特写、奔跑、山顶）、镜头运动和整条时间线 |
| `src/scene.html` | 渲染入口，`renderFrame(t)` 画出 t 秒的画面（种子随机数，结果固定） |
| `src/score.py` | 配乐和音效（numpy），并混入 `src/voice/` 里的人声 |
| `src/voice.py` | 用 sherpa-onnx + MeloTTS 中文模型重新生成两句台词（女孩那句升调约 3 个半音） |
| `src/render.js` | Playwright 驱动 Chromium 逐帧渲染，送进 ffmpeg 编码 |
| `src/player.html`, `src/pack.py` | 播放页模板和打包脚本 |
| `src/preview.js` | 调试用：只渲染几个时间点的静帧 |

重新生成需要 python3 + numpy、node + playwright（自带 Chromium）、ffmpeg：

```sh
./build.sh
```

会先 `npm install` 字幕用的霞鹜文楷字体，在 4 核机器上全部跑完大约 4 分钟。
