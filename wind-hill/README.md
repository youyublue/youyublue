# 风之丘 · The Wind Hill

一部 46 秒的手绘动画风格短片：夏日午后，大朵积云下的山丘上，一个戴草帽的女孩站在大树旁。一阵风吹过草地，把她的草帽卷上了天空，镜头跟着帽子一路升进晚霞。

整部片子由代码逐帧画出，配乐也是程序合成的，没有用到任何外部素材。

## 文件

- [`index.html`](index.html)：单文件播放页。视频以 base64 嵌在页面里，无依赖，下载后用浏览器打开就能离线看。
  - 自制播放器：播放/暂停、拖动进度、全屏、打开声音；自动播放被拦截时会退到静音播放
  - 胶片颗粒在 `<canvas>` 上实时生成
  - 快捷键：`Space`/`K` 播放暂停 · `←`/`→` 跳 5 秒 · `M` 静音 · `F` 全屏
- [`wind-hill.mp4`](wind-hill.mp4)：同一部片子的普通视频文件（1920×1040，24 fps，H.264 + AAC），方便直接分享。

## 怎么做出来的

| 文件 | 作用 |
|---|---|
| `src/scene.html` | 画面。`renderFrame(t)` 用 Canvas 2D 画出 t 秒时的画面，种子随机数保证每次结果一致 |
| `src/score.py` | 配乐。numpy 合成钢琴琶音、F 大调旋律、弦乐铺底、跟画面同一条阵风曲线的风声，加卷积混响 |
| `src/render.js` | 用 Playwright 驱动 Chromium 逐帧渲染，JPEG 帧直接送进 ffmpeg 编码并混入音轨 |
| `src/player.html` + `src/pack.py` | 播放页模板，把视频和封面打包成 `index.html` |
| `src/preview.js` | 调试用：只渲染几个时间点的静帧 |

画面上的几个做法：

- **积云**：每朵云由若干"团块"组成，每个团块由一圈圆组成。先铺阴影色，再铺向左上偏移的亮色，最后叠一层柔和高光，底部切平并加一道冷色渐变。
- **风**：同一个 `wind(x, y, t)` 函数驱动草叶弯曲和亮暗色带、树冠摆动、裙摆和头发、飞叶，配乐里的风声也用同一条阵风曲线。
- **镜头**：开场从天空下摇到山丘，然后推近女孩；帽子飞走后镜头跟着帽子上摇，远近各层按不同视差移动。

重新生成需要 python3 + numpy、node + playwright（自带 Chromium）和 ffmpeg：

```sh
./build.sh
```

在 4 核机器上全部跑完大约 2 分钟。
